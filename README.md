«FanBiz, homenaje a GameBiz»

FANBIZ 1.0
==========

ESPAÑOL
-------
FanBiz es un homenaje a GameBiz, el clásico simulador de estudio de videojuegos: dirige tu empresa de 1983 a 2030.
Juego de aficionado y sin ánimo de lucro, hecho con Godot 4. Idiomas: español e inglés (cambia desde el menú principal).

Windows: descomprime el zip y ejecuta FanBiz.exe. Si Windows muestra «Windows protegió su equipo» (SmartScreen),
pulsa «Más información» y luego «Ejecutar de todas formas»: el programa no está firmado digitalmente.
Linux: descomprime, abre una terminal en esa carpeta, ejecuta  chmod +x FanBiz.x86_64  y después  ./FanBiz.x86_64

Partidas y ajustes: se guardan automáticamente en
  Windows: %APPDATA%\Godot\app_userdata\GameBuzz   (o  %APPDATA%\godot\app_userdata\GameBuzz)
  Linux:   ~/.local/share/godot/app_userdata/GameBuzz
Para desinstalar basta con borrar la carpeta del juego (y, si quieres, esa carpeta de partidas).

Créditos: creado por JG con la ayuda de Claude; música de Imageniero (www.imageniero.com , imageniero.bandcamp.com).
Basado en el código liberado de la primera parte de GameBiz. Sin relación con VelociGames ni GameBiz 4.
Los nombres de plataformas y juegos de cada época aparecen solo con fines de ambientación.

ENGLISH
-------
FanBiz is a tribute to GameBiz, the classic video game studio simulator: run your company from 1983 to 2030.
A free fan game built with Godot 4. Languages: Spanish and English (switch from the main menu).

Windows: unzip and run FanBiz.exe. If Windows shows "Windows protected your PC" (SmartScreen), click "More info" and
then "Run anyway": the program is not digitally signed.
Linux: unzip, open a terminal in that folder, run  chmod +x FanBiz.x86_64  and then  ./FanBiz.x86_64

Saves and settings are stored automatically in
  Windows: %APPDATA%\Godot\app_userdata\GameBuzz   (or  %APPDATA%\godot\app_userdata\GameBuzz)
  Linux:   ~/.local/share/godot/app_userdata/GameBuzz
To uninstall, just delete the game folder (and that saves folder if you wish).

Credits: created by JG with help from Claude; music by Imageniero (www.imageniero.comn , imageniero.bandcamp.com).
Based on the released source code of the first GameBiz. Not affiliated with VelociGames or GameBiz 4.
Platform and game names from each era appear for period flavour only.
